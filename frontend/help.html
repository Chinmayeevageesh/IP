How to Use CampusConnect

A quick guide to using the campus academic resource network.

1. Browse Resources

Open Browse Resources to view academic materials available across the campus nodes. Use the search box to find a resource and click Download to access it.

2. Upload Resources

Open Upload Resources, enter a resource ID, choose a file and click Upload Resource. The network stores and verifies enough replicas to meet quorum 3. Files must not exceed 10 MB.

3. My Uploads

View the resources uploaded through your current browser. You can use the Download button to retrieve them.

4. Network Status

Check whether Nodes A, B, C and D are online or unreachable in the admin dashboard. The page automatically refreshes node information.

5. File Integrity

CampusConnect uses SHA-256 hashing to generate file integrity checksums and help detect changes to stored resources.

Troubleshooting
  • If a node is unreachable, check whether its backend server is running.
  • If an upload fails, check the file size and whether at least three campus nodes are online.
  • If a download fails, verify that the resource is still stored on its node.
  • Keep the required backend node servers running while using the prototype.
Note: CampusConnect is an academic prototype demonstrating offline-first resource sharing through simulated campus nodes.
